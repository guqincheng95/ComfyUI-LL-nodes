# LL 人像色彩对齐 · Portrait Color Align

在「LL 节点库／图像后期／基础调色」下搜索「人像色彩对齐」。适用于换装、换背景后，想沿用原图白平衡和人物肤色的场景。原「LL 后期修图」继续保留。

打开「实时预览」并运行一次后，可拖动手动滑块看效果。见 [调色节点实时预览](PHOTO_LIVE_PREVIEW.md)。

1. **待调图**接生成结果，**参考图**接希望对齐颜色的原图。两张图可以不同画幅、动作和尺寸。
2. **白平衡**先从两张图的低饱和区域估算色温和绿／洋红色调。若背景本身颜色不同、画面没有足够灰白区域，分别接中性取样遮罩，圈出应当同为中性色的墙面、灰卡等；遮罩只负责取样，白平衡仍作用于全图。不要圈灯泡或死白高光。
3. **肤色**分别取待调图和参考图的脸部、身体可见皮肤。某一区域任一侧无有效样本就跳过；例如战衣遮住身体，脸仍可调，衣服不参与局部肤色校正。脸部及身体默认保留校正白平衡后的明暗，仅校正颜色。
4. **手动精调**用原有曝光、色温、色调折叠区。手动值在自动处理之后生效。右侧「自动校正报告」可接任意兼容 STRING 的文本显示节点，查看每张图三个区域的样本数、计算出的色温／色调／曝光与跳过状态。自动参数不会写回手动滑块。

| 肤色分区来源 | 怎么用 |
|---|---|
| 外部遮罩（默认） | 接上游皮肤分割或手绘的 MASK。同一区域在两张图都接；只想校正脸，就只接两张脸部 MASK。白色 1 是选区，黑色 0 是未选区；可用软边。脸部排除嘴唇、眼睛、头发，身体排除服装和手套，勿接整人 MASK。 |
| 本地人体分割 ATR | 使用节点库已有的可选 ATR ONNX。脸部取脸类，身体取可见臂／腿候选，并用颜色和置信度减少把袖子、裤袜当皮肤。上游遮罩优先，可只替换误判的一侧或一区。见 [ATR 安装与权重许可](SUBJECT_PRUNING.md#本地atr模型配置与许可)。模型不随安装包分发，不会自动下载；商用工作流建议接已有授权的外部遮罩。 |
| 仅白平衡 | 不做局部肤色校正。全身遮挡且无可见皮肤时可直接选此模式。 |

初试可用默认值：白平衡 **0.85**、脸部 **0.8**、身体 **0.8**、肤色明暗匹配 **0**。肤色明暗匹配调高后会有限度地追近对应区域的亮度，不会把参考图的光影形状复制过来。遮罩尺寸须等于各自对应图片，批量时支持单张参考广播。

ATR 的臂／腿标签不能保证是裸露皮肤，自动模式仍可能漏掉颈胸、手指和强偏色皮肤，或误把接近肤色的布料识别成皮肤。出现这些情况时改接准确的外部遮罩。两个输入图像按显示用 sRGB 处理，报告数值和手动滑块共用色温／色调运算；曝光报告为相对 EV。
