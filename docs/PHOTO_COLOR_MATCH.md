# 后期修图 v0.5：自动对齐、参考仿色与折叠调色

更新整个 `comfyui-LL-nodes` 后重启 ComfyUI，再在浏览器 Ctrl+F5。节点仍在“LL 节点库 / 图像后期 / 基础调色”，可搜索“LL 后期修图”“自动仿色”“曝光”“白平衡”或 `AIVisualPhotoFinish`。

## 接线与模式

| 输入 / 设置 | 原图对齐 | 参考仿色 |
|---|---|---|
| `image`（图像） | 放大或二次采样后、需要校正的图片 | 需要调色的图片 |
| `reference_image`（原图／仿色参考图） | 放大或二次采样之前的原图 | 想借用色调的参考图片 |
| 自动对齐模式 | 原图对齐（同画面） | 参考仿色（不同图片） |
| 尺寸要求 | 可以大小不同；构图、裁切、人物位置应一致 | 内容、尺寸、宽高比可以不同 |

“关闭”是默认值，因此旧工作流不连接参考图也能继续使用。开启匹配而没有连接参考图时，会提示补接参考图。执行顺序是**自动匹配 → 手动调色 → 输出**，一次节点运行即可完成。

原图对齐利用同画面的对应色彩拟合整体色偏，适合放大、轻度重绘或二次采样后的色温、曝光和色彩漂移。如果二次采样已经大幅改变构图，改用参考仿色更合适。宽高比差异超过 2% 会提示切换模式；同宽高比也需要自行确认是同一构图。

参考仿色利用明暗分位数，以及阴影、中间调、高光的颜色均值与分布，尽量靠近参考图的整体调子。它按整张图的统计工作；例如参考图有大量白雪，明暗匹配也可能把目标整体提亮。此时降低“明暗／色阶匹配”，保留较高的“色彩匹配”，再手动微调曝光。

## 匹配强度

| 控件 | 范围 | 用法 |
|---|---|---|
| 自动匹配总强度 | 0～1，默认 1 | 控制两类匹配的总量；0 时仅运行手动调色 |
| 明暗／色阶匹配 | 0～1，默认 1 | 调整整体亮度分布、暗部至亮部的关系 |
| 色彩匹配 | 0～1，默认 1 | 调整颜色偏移与分布；设 0 可仅匹配明暗 |

原图对齐可先用三个 1；仿色可先把总强度设为 0.5～0.8，再按画面调整。独立强度是在 Oklab 空间混合明暗与颜色，超出显示色域时会压缩颜色，因此极端颜色的两者无法完全独立。

支持 RGB / RGBA 浮点 IMAGE；单张参考图可以用于整个目标批次，或参考图数量与目标批次一致、逐张对应。统计图会缩小以节省开销，输出仍保留目标尺寸、细节和 Alpha；透明区隐藏的 RGB 不参与可见颜色统计。不增加模型下载或额外 Python 依赖。

## 三个手动折叠区

| 折叠区 | 参数 |
|---|---|
| 曝光 | 曝光、对比度、高光、阴影、白色、黑色 |
| 色温 | 色温、色调（绿／洋红） |
| 色调 | 自然饱和度、饱和度、阴影／中间调／高光的三组色彩平衡，以及保持色彩平衡明度 |

默认收起；点击标题展开。收起只隐藏界面，参数继续生效，标题会显示已调整项数。工作流保存时保留展开状态及所有数值。旧工作流的 19 个数值参数和布尔开关顺序保持兼容，新自动控件追加在后。

v0.6.1修复折叠条和滑块溢出：按ComfyUI DOM空间统一边距与高度，支持窄节点和画布缩放，展开收起不会再强制把窄节点拉回360px。更新后重启并Ctrl+F5；无需重新安装Python依赖或下载模型。定位和验证见[PHOTO_UI_LAYOUT.md](PHOTO_UI_LAYOUT.md)。

滑块左负右正、两侧各 10 档，中间为 0；保留左右微调按钮和数字输入。曝光滑块每档 0.5 EV、按钮每次 0.05 EV，其余滑块每档 10、按钮每次 1。数字可以输入档位之间的精细值；双击滑块归零。

## 滑块色带

| 控制 | 左侧负值 | 零位 | 右侧正值 |
|---|---|---|---|
| 光影六项 | 黑 | 中灰 | 白 |
| 色温 | 蓝 | 白 | 橙 |
| 色调 | 绿 | 白 | 洋红 |
| 青／红 | 青 | 白 | 红 |
| 洋红／绿 | 洋红 | 白 | 绿 |
| 黄／蓝 | 黄 | 白 | 蓝 |
| 自然饱和度／饱和度 | 灰 | 白 | 彩色 |

互补色色带越靠两端，颜色越深、越饱和。色带是调节方向提示，算法及数值含义保持原样。

## 使用范围与示例

此节点用于可显示 sRGB 图像的颜色匹配和调整，不进行物体识别或风格迁移。不同内容的图片，其颜色面积差异可能影响统计匹配，肤色也会参与全图计算。完全过曝、死黑或已丢失的信息无法由统计方法恢复；PNG 文件扩展名本身不等于更大动态范围，实际取决于输入位深、编码及是否已发生裁切。

新示例：`examples/photo/reference_match_workflow.json`（拖进 ComfyUI）和 `reference_match_api.json`（API 格式）。先为两个加载图像节点选择待调图和原图；默认使用原图对齐，换参考图片时切换到“参考仿色”。原 `minimal_*` 示例继续保留。
