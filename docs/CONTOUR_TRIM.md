# LL 人物轮廓修剪 · v0.4.0

目标：清除深度图里向身体外部扩展的头饰、裙摆、宽袖和飘带，使动作条件较少携带原服装形状。保留区域直接使用原深度；不重新生成身体，不进行遮挡补全，不改变画布或人物位置。

## 按现有工作流接线

| 已有输出 | 新节点输入 |
|---|---|
| Depth Anything V2 的 IMAGE（混合前） | 原始深度图 / depth_image |
| SDPoseKeypointExtractor 的 keypoints | 人物关键点 / keypoints |
| 原图经 BEN2 图像背景移除的 mask | 原图人物遮罩 / foreground_mask（推荐） |

把新节点的“修剪后深度图”接回原先深度图去往的混合图像输入。原有 SDPose 骨架绘制支路继续接原来的混合图像节点。**不要把已经叠加彩色骨架的图片作为深度图输入。** 不需要重新检测一次骨架，也不需要下载新模型。

输出“修剪对比预览”接预览图像：绿色表示保留，红色表示被裁掉的非背景区域。输出“人物保留遮罩”为白色保留、黑色去除。输出“处理说明”包含成功/安全保留帧数，可接显示文本节点。

## 为什么推荐原图的前景遮罩

骨架提供姿态位置，原图经成熟抠图模型得到的前景 MASK 提供实际可见轮廓。沿手臂、躯干和腿部的横向截面观测边界；只在合理的局部范围内调整保留宽度。宽裙摆和披风如果远超观测上限，不会把保留范围无限扩大。

这属于“可见轮廓观测 + 姿态约束”，不是人体测量模型。宽度仍有合理范围的几何估计；贴着身体的服装、正常头发和较厚衣服可能需要放宽对应部位。前景 MASK 最后与保留区域取交集，原图中的身体空隙/背景不会被填出来。

## 参数与建议

- 首次使用保持四个宽度倍率均为 1，边缘保护 4 像素、柔化 2 像素。
- 头饰外扩仍明显：逐步减小头部保留宽度，如 0.9；正常头发被切则放大，或接额外保留遮罩。
- 误切肩胯、手臂或腿部：放宽对应倍率，每次增加 0.05～0.1，观察对比预览。
- 裙摆残留：收紧腿部倍率及边缘保护；位于躯干/腿部范围内部的裙子不会被语义识别并全部删除。
- 连续单人视频可设稳定强度 0.2～0.3。只平滑当前批次中的关键点，不混合前后帧遮罩；独立图片使用 0。批次之间无状态，因此视频分批边界可能仍需检查。
- 人物序号 0 是第一人，-1 是全部人物；没有身份跟踪，多人自动关闭时间平滑。
- 坐标格式默认自动，支持 OpenPose BODY_18 与 BODY_25；SDPose 为像素坐标。不要把 COCO17 原始数组直接接入。
- 裁剪填充值默认 0（黑）。如果后续深度条件有其他背景约定，应按约定修改。

## 复用已有成熟分割能力

额外的 MASK 接口可以直接接受现有分割节点输出，无须重复开发语义分割：

- **额外保留遮罩 / protect_mask**：白色保留手、脚、正常头发等范围，仍与原图人物遮罩取交集。
- **明确去除遮罩 / exclude_mask**：白色明确删除帽子、头饰或其他区域，优先级最高。

可由 Cozy Human Parser、其他人体/服饰分割节点，或手绘 MASK 提供。自动轮廓模式不会准确识别每一种服饰类别；靠近头部/躯干内部的饰品需要明确去除遮罩才能可靠删除。本节点不自带这些分割模型。

处理优先级：骨架与前景拟合 → 边缘保护/柔化 → 额外保留 → 与原图人物遮罩取交集 → 明确去除。

## 批量和错误保护

- 一张图对应一帧关键点；视频帧数必须一致。
- 单帧骨架可重复用于静态批量，会在处理说明中提示；运动视频应逐帧连接。
- 遮罩支持 [H,W] 或 [1,H,W]/[B,H,W]；必须来自同一裁切范围；等比例分辨率差异自动缩放遮罩到深度图尺寸，并在处理说明中提示。宽高比差异超过2%会报错，避免把不同裁切直接拉伸。
- 身体主关键点不足时默认保留该帧的原图前景并报告原因。可改成“报错停止”。本版偏向全身人物；上半身裁切、严重遮挡和检测失败可能触发安全保留。
- 即使触发安全保留，显式去除 MASK 仍会执行。
- 保留内部原深度浮点数；只在柔化边缘发生背景混合。RGBA 输入的 Alpha 随保留遮罩裁切。

## 示例与验证范围

`examples/contour/minimal_workflow.json` 可拖入 ComfyUI；`minimal_api.json` 是对应 API 示例。选择自己的原图和已有 SDPose 权重，示例依赖已安装的 comfyui_controlnet_aux。示例的前景遮罩端口留空，正式使用建议接入已有 BEN2 的 MASK。

本地完成了合成裙摆/头饰测试、公开真实人物标注样例的轮廓目视检查、浮点数据和批量测试。没有运行用户完整生图链路，也没有在用户 ComfyUI 服务端验证生成质量。具体见 TEST_REPORT.md。
