## 图像检查

使用 NASA 宇航员公开样例与 COCO 785 滑雪人物照片进行内部目视检查，照片及截图不打包。宇航员图做2倍双线性放大，再添加已知线性RGB偏移作为测试输入；原图对齐后与放大原图接近。未裁切像素 MSE 从 0.000642668 降到 0.00000139626（此受控样本减少99.78%），详见 photo-match-metrics.json。这不是实际扩散重采样样本，不能推断通用校正率。

同一次开发环境 CPU 2线程采样：1024×1024原图对齐约0.208秒；512×512参考仿色约0.077秒。仅单次样本，不代表用户GPU速度。仿色样例的雪景参考让目标变亮、偏冷，符合全图统计特征；不同内容可降低明暗强度控制这种变化。
