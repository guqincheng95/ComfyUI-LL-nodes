# 调色节点实时预览

适用于「LL 人像色彩对齐」及「LL 后期修图（兼容版）」。

1. 接入待调图，按需要接参考图或遮罩。确认图像输出已接到「预览图像」或保存节点，让该节点参与工作流。
2. 打开节点的「实时预览」，**先运行一次**。节点下方会出现自动校正后的首张缩略图；自动关闭时，使用输入图作为底图。
3. 展开曝光、色温或色调，拖动手动滑块、点微调按钮或输入数字，预览随当前值更新。点击「看校正底图」可对照应用手动调整前的效果，再点「看手动效果」返回。
4. 换图、换参考图或遮罩，或改变白平衡／肤色／整图仿色等**自动**参数后，重新运行一次刷新底图。最终保存或将参数应用到下游时仍需运行工作流。

预览在浏览器内用 WebGL2 处理，不提交额外任务，不重复加载模型。只预览批次第一张，缩略图长边最多 640；正式输出的分辨率、批次数量和后端计算不变。缩图后的局部细节、放大查看和极端高光以正式结果为准。不开启时不生成预览数据。浏览器如果不支持实时预览，仍可使用常规「预览图像」。

新工作流建议用「LL 人像色彩对齐」。旧后期节点移到「LL 节点库／图像后期／兼容与整图仿色」，保留其整图仿色、原图对齐和原有连线。

## 清理重复安装

不要在 `custom_nodes` 同时保留统一节点库、旧独立 `ComfyUI-PhotoFinish` 或旧独立 `ComfyUI-ResolutionPreset`。脚本也识别通过不同文件夹名保留的重复统一版（例如 `ComfyUI-LL-nodes-main` 或 `ComfyUI-LL-nodes-v0.9.0`）。

停止 ComfyUI，在**要保留的新版节点库目录**执行（也可把 `python` 换成整合包的 Python）：

```bash
python scripts/migrate_legacy.py
python scripts/migrate_legacy.py --apply
```

第一条只列出目标，第二条把已识别的旧目录移到 `ComfyUI/ll-nodes-backups`，保留文件和旧工作流。完成后重启 ComfyUI，浏览器 Ctrl+F5。
