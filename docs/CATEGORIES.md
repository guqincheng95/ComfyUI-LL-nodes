# LL 节点库分类规范

统一根分类：`LL 节点库`。按用途分类，不按模型名或版本号分组。

| 下级分类 | 当前节点 | 源码模块 |
|---|---|---|
| 图像工具 / 尺寸与比例 | LL 比例预设 | modules/resolution |
| 图像工具 / 人物轮廓 | LL 人物轮廓修剪 | modules/contour |
| 图像后期 / 基础调色 | LL 后期修图 | modules/photo |

Z-Image、Krea 2 等适配属于尺寸预设内部选项或兼容说明，不各自创建重复分类。
后期的曝光、白平衡、色彩平衡是同一节点的参数，不拆成三个重复节点。
将来有真实功能时再新增“图像后期/局部处理”“视频工具”等分类，不预先创建空节点。

新增节点：代码放 modules/用途目录，根 __init__.py 显式注册；展示名使用 LL 前缀和清晰中文，内部类型标识发布后保持稳定。前端统一放 web，语言资源合并到 locales/zh/nodeDefs.json，示例与测试同步添加。禁止嵌套另一个可独立安装的 addon 造成重复注册。
