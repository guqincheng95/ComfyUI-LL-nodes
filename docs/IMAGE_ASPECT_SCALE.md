# LL 图像比例控制

搜索“LL 图像比例控制”或“Image Aspect Scale”。分类：LL 节点库 / 图像工具 / 尺寸与比例。原“LL 比例预设”用于生成固定宽高，本节点用于处理已有图像、深度图或遮罩。

| 设置 | 使用方式 |
|---|---|
| 画面比例 | 原图比例、常用横竖比例，或自定义比例宽／高 |
| 反转宽高比例 | 例如 3:2 → 2:3；改变输出画布比例，图像不旋转 |
| 适配方式 | 居中裁切填满画布；等比补边保留完整构图；拉伸可改变形状 |
| 尺寸依据 | 最长边、最短边、宽度、高度、总像素（千像素）、保留原长边 |
| 目标值 | 按边设像素；总像素模式下 1000 = 100 万像素；保留原长边时忽略 |
| 像素倍数 | 宽高分别取整到输入的倍数，1 表示无需倍数对齐 |
| 取整方向 | 就近（正好居中时向上）、向上、向下；每边至少一个倍数 |
| 插值 | Lanczos、双三次、Hamming、双线性、Box、最近邻；遮罩可独立选择同图像／双线性／最近邻 |
| 补边颜色 | 点击「吸管」在屏幕上取色，也可点击色块打开调色盘或输入 HEX；MASK 补边仍为 0 |

**取色示例：** 选择「等比补边」，点击「吸管」，然后点击参考图中想匹配的背景像素，再运行工作流。Esc 取消取色。屏幕吸管需要支持 EyeDropper 的浏览器及安全上下文（如 Chrome／Edge 的本机地址或 HTTPS）；吸管不可用时可使用色块调色盘。颜色沿用原有 HEX 字段，保存后随工作流恢复；该输入接线时由上游颜色控制。

示例：原图比例 752×1392，最长边 1280，8 倍数、就近取整，输出 **688×1280**。尺寸对齐后比例、总像素和指定边长可能略偏离目标，以输出宽高为准。16:9、宽度1280、倍数8，输出 **1280×720**。

输入至少接一路 IMAGE 或 MASK。图像与遮罩须来自同一构图、同一裁切范围；宽高比差异不超过 2% 时，可把不同分辨率的遮罩先对齐到图像。已裁掉不同内容的输入仍要先手动统一构图。图像批次可以配同数量的遮罩，或广播一个遮罩。相同的裁切框、缩放尺寸和补边位置用于两路。

输出顺序为图像、遮罩、原始尺寸（BOX，`[宽, 高]`）、实际输出宽、实际输出高。RGB 单接时，MASK 表示图像覆盖区域（内容 1、补边 0）；RGBA 单接时，Alpha 转为 MASK，图像输出 RGB。显式 MASK 优先，不反相、不乘到 RGB 上。仅输入 MASK 时，图像输出是灰度预览。二值遮罩可选择最近邻；软遮罩可选双线性。无额外模型和依赖安装。

本节点不改变原插件的 Z-Image 等预设。工作流示例位于 `examples/resolution/aspect_scale_workflow.json`，API 示例为 `aspect_scale_api.json`。示例使用 LoadImage 的 IMAGE 输出；需要输入自己的 MASK 时请接同构图的实际遮罩，普通无透明图片的 LoadImage 占位 MASK 不需要连接。

功能参考：[LayerStyle ImageScaleByAspectRatio V2](https://github.com/chflame163/ComfyUI_LayerStyle/blob/main/py/image_scale_by_aspect_ratio_v2.py)。不依赖 LayerStyle。
