# LL DLSS5 图像增强 · v0.12.1

本模块是基于 [Blueforcer/ComfyUI-DLSS5-Enhancer](https://github.com/Blueforcer/ComfyUI-DLSS5-Enhancer) 的适配开发，复用其 MIT 原生客户端；增强能力来自 NVIDIA DLSS5，而非 LL 自训练模型。第三方运行时独立下载，仓库与代码 ZIP 不包含这些二进制。来源和修改见 [DLSS5_UPSTREAM.md](DLSS5_UPSTREAM.md)。

## 一个主节点完成全部功能

**加载图像 → LL DLSS5 图像增强 → 保存／预览图像**。默认原生整图增强，不需要设置节点、分割模型或遮罩。倍率和预设直接在主节点调整，展开高级设置后可调原生光影、结构、人物／环境强度、边缘和色彩保护等参数。

| 需求 | 主节点内的操作 |
|---|---|
| 原版整图增强 | 保持“原生默认＋自动”，只连接图像；输出原生RGB |
| 人物／环境分区 | 接完整人物MASK，或选择人像／均衡／环境预设，或明确选择分区增强 |
| 自定义原生参数 | 选择原生直出，展开高级设置调整光影／结构／风格 |
| 自定义区域参数 | 选择分区增强／自定义，展开高级设置调整人物与环境强度 |
| 局部对比 | 开启“节点内对比预览”，在本节点显示左原图、右结果；可接ROI遮罩或调整局部坐标 |
| 调整输出倍率 | 直接修改主节点的输出倍率，不再另接设置节点 |

默认原生参数为1x、M、默认风格、光影1.0、结构1.5、皮肤结构2.0、原生皮肤识别开启。原生输出不运行LL分区混合、统一光影分离、中性色／肤色保护；没有外部分割模型参与。RGBA的Alpha独立保留／缩放；帧历史、显存释放、取消和神经渲染验证保持有效。

高级参数根据原生／分区、图片／视频路径显示；对比和低分辨率预览有各自开关，隐藏参数不丢值。选择预设时主节点同步显示对应数值；手动修改预设控制的值时自动进入自定义，并保留分区处理方式。关闭高级显示不重置已调数值。

节点内对比只显示首帧，先完整增强再裁切，保存到ComfyUI临时预览目录；不改变下游image／MASK／report输出，不需要另接对比节点。关闭该开关则不创建对比预览文件。

旧的LLDLSS5Settings、LLDLSS5Compare保留注册以兼容历史工作流，但均标记DEPRECATED并移到“LL节点库/兼容节点/DLSS5旧版”；只有主节点是当前推荐节点。启用显示弃用节点时仍可能看到两个旧项。连接旧settings时其参数优先，主节点隐藏被覆盖的内置参数；旧连接、控件及输出顺序不变。新增控件均追加，未插入旧控件序列。

示例：[native_api.json](../examples/dlss/native_api.json)仅图像；[minimal_api.json](../examples/dlss/minimal_api.json)一个主节点完成分区及内嵌预览。

## 安装与自动部署

支持 Windows 64位；本适配沿用协议 v4 的 Visual Enhancer v3.0。官方 DLSS5 面向 RTX50；社区运行时的 RTX40、RTX30 路径需要实机验证，RTX30必须匹配指定二进制。RTX20、AMD、Linux 本轮不支持；其它 LL 节点继续正常使用。多卡只能检测兼容候选，底层未提供 GPU 索引选择，不承诺按检测结果选卡。

**默认不需要手动运行安装脚本。** 更新并重启ComfyUI后，第一次执行主节点会检查环境；缺少依赖、运行时或FFmpeg时自动调用部署逻辑，完成后继续当前增强任务。已有可用环境直接复用，不重复下载。高级设置中的“首次运行自动部署”默认开启，可关闭后自行准备离线环境。

准备阶段使用当前ComfyUI进程对应的Python，先于增强模块导入修复可选依赖；默认释放已加载模型显存，为原生自检留空间。安装／下载／校验／解压／自检支持取消，同进程同时触发只执行一次部署，文件锁防止跨进程并行覆盖。Comfy进度条显示准备阶段，详细下载速度与来源在控制台。

ComfyUI-Manager的install.py钩子和手动setup_dlss5.bat作为提前部署／排错入口保留。只有直接使用这些手动入口时才需要下面的命令。少数已加载框架无法热启用新二进制依赖时会提示重启，不会无限循环覆盖Torch/CUDA。

批处理自动寻找官方便携版 `python_embeded`、秋叶版 `python`、ComfyUI 的 `.venv/venv`。找不到时设置 `LL_COMFY_PYTHON` 为运行 ComfyUI 的 Python 路径，或直接运行 Python 入口。不会退回不明确的系统 Python。

你的秋叶目录，在 PowerShell 可直接执行：

```powershell
& "L:\AI\ComfyUI-aki-v3.2\python\python.exe" "L:\AI\ComfyUI-aki-v3.2\ComfyUI\custom_nodes\comfyui-LL-nodes\setup_dlss5.py"
```

脚本执行顺序：

1. 检查当前 Python、Windows/D3D12、NVIDIA GPU和驱动可见性、Torch、numpy、OpenCV、运行时、FFmpeg/ffprobe。
2. Torch无法导入时停止，提示切换正确的 ComfyUI Python。保留现有 Torch/CUDA、numpy和可用 OpenCV；不替换 opencv-contrib。
3. 仅通过当前 Python 安装缺失的 numpy/OpenCV。已有 OpenCV 发行包但导入失败时要求修复原环境，避免叠装多个版本。
4. 优先复用已配置运行时／原作者节点的同级兼容安装；缺少时下载固定 v3.0 原包，约467MB。
5. 校验官方发布资产的 SHA-256，再暂存解压 runtime和FFmpeg，目录替换失败回滚；有安装锁避免同时部署。
6. 启动512×512真实原生测试，验证协议与签名 DLSSNR feature18 初始化、创建、执行证据。通过后记录路径和 `runtime/dlss5/setup-report.json`。重复运行复用已有文件，不重复下载。

**驱动版本字符串可读取不代表驱动必然兼容，最终由原生自检确认。** 驱动、Windows组件及硬件条件不满足时给出诊断，不擅自升级显卡驱动或改系统安全设置。自检卡住会超时结束。导入不联网；主节点执行时在缺失环境且自动部署开启的情况下才联网准备。

以下命令在节点库目录执行，`python`必须是 ComfyUI 当前环境的解释器：

```powershell
# 只检测，不安装、不写文件；缺失时退出码2
python setup_dlss5.py --check

# 离线：从原作者发布页另行下载未经重打包的 v3.0 ZIP
python setup_dlss5.py --archive "D:\Downloads\DLSS.5.Visual.Enhancer.v3.0.zip"

# Python依赖也离线安装（准备与当前Python/Windows匹配的wheels）
python setup_dlss5.py --archive "D:\Downloads\DLSS.5.Visual.Enhancer.v3.0.zip" --wheel-dir "D:\wheels"

# 复用原作者完整runtime目录
python setup_dlss5.py --runtime-dir "D:\DLSS 5 Visual Enhancer\bin\runtime"

# 可选Python镜像；只对缺失依赖生效
python setup_dlss5.py --index-url "https://你的Python镜像/simple"

# 自选下载代理前缀，后面自动拼接完整GitHub原始URL，仍严格校验同一SHA256
python setup_dlss5.py --download-prefix "https://你的下载代理/"
```

固定原包：[Visual Enhancer v3.0](https://github.com/Merserk/dlss5-visual-enhancer/releases/tag/v3.0)。不能用“最新版”或另一个 v15/v17 CLI包替换；接口不同。SHA256：`6f0590d81677484f4ecdfaa5c44fc2a0e1a3835d33eefc59d656e6c3bcf35f6a`。

`--skip-self-test`只部署文件和依赖，报告明确标记原生执行未验证；`--force`重新部署固定包。失败时控制台保留原因；正常脚本无须管理员权限。手动强制重装前停止DLSS任务，避免DLL被占用；正常首次执行会自动准备。

## 下载来源与网络适配

运行时原包约467MB，PyPI镜像不能代替这个GitHub Release资产。默认同时测试GitHub原始地址、ghfast.top和GH-Proxy加速入口，读取少量数据测量实际吞吐，再选择更快的来源；测速失败的来源仍可作为后备尝试。它们是公共第三方加速入口，不是NVIDIA官方国内镜像，不承诺固定带宽。参考服务说明：[GH-Proxy](https://gh-proxy.com/docs/github-accelerator)。

- 有HTTP代理时会比较加速入口的系统路由与不经HTTP代理的连接，GitHub仍使用系统路由；不修改全局代理或系统网络配置。TUN仍由操作系统路由，不能把“未检测到HTTP代理”等同于未代理。
- urllib使用系统／环境HTTP代理；浏览器扩展、PAC或SOCKS端口不保证对Python生效。可在主节点高级设置填写明确的HTTP/HTTPS代理地址，或用 `--http-proxy`，不猜测本机端口。
- 控制台显示当前来源、MB/s、已下载／总量和预计剩余秒数。持续低速且有其它候选时保留分片换源；网络失败或取消保留 `.part`。
- 续传严格检查HTTP206、Content-Range、文件总大小和重叠字节，防止重复拼接。不支持续传的来源只能另行完整下载，旧分片保留到完整文件校验成功。
- 所有入口必须通过同一个原始发布资产SHA256；HTML验证页面、错误大小或错误哈希不得安装。TLS校验保持开启，不下载执行远程安装脚本。
- 高级“仅GitHub原始来源”／CLI `--official-only` 可关闭公共加速入口。自选 `setup_download_prefix`／`--download-prefix` 会加入测速候选；不能与仅官方来源同时使用。
- 缺失Python依赖且未指定index／PIP_INDEX_URL时，优先清华PyPI镜像，安装失败尝试PyPI原始源；明确配置或离线wheel优先。已有numpy／OpenCV保持现有版本，不替换opencv-contrib。镜像说明：[清华TUNA](https://mirrors.tuna.tsinghua.edu.cn/help/pypi/)。

已下载完整ZIP、已有运行时和已验证缓存会复用。旧版下载脚本取消时可能自行清理旧分片，旧进程的清理行为不会因更新代码而改变；新版的保留／续传只对新版下载器保证。不要同时启动多个安装进程。

## 接线

- 原始完整图像接主节点image，主节点image输出接保存／预览图像。
- 分区可选：完整人物分割MASK接person_mask；可见皮肤MASK接skin_mask。均不需要另一个LL设置节点。
- 对比可选：开启节点内对比预览；roi_mask只指定对比范围，不参与分区或渲染。
- 旧settings输入仅用于兼容，可不接。若已接，内置参数不覆盖外部设置。

人物遮罩应保留头发、衣服、饰品的完整轮廓。不要把之前为动作迁移删除头发／裙摆／头饰的身体裁剪MASK当作完整人物MASK，否则删去的部分会按环境强度处理。皮肤MASK只包含可见皮肤，排除眼唇、衣物及遮挡。

遮罩允许不同分辨率，按相同归一化坐标缩放；宽高比明显不同时停止，提示统一裁切／补边。单张可广播，视频批量必须逐帧对应。

## 处理逻辑与像素边界

每帧只有一次整图原生渲染。原图与增强图在同一输出网格融合，Alpha单独保留；透明图缩放使用预乘颜色，避免隐藏RGB污染边缘。原生输入／输出仍为8位SDR，浮点融合不代表模型支持16位／HDR。

| 区域融合方式 | 人物／环境强度的作用 | 光影处理 |
|---|---|---|
| 统一光影・细节分区（默认） | 主要控制高频变化 | 整图共享低频变化，统一光影强度独立控制 |
| 全部变化分区 | 控制该区域的全部增强变化 | 光影也按人物／环境强度混合；统一光影强度忽略 |

低高频分离是图像处理近似，不是读取 DLSS模型内部的灯光与材质层。统一光影模式中人物强度0仍会有光影变化；要完全冻结人物请选“自定义＋全部变化分区＋人物0”。关闭两项色彩保护后才是纯区域混合。

融合使用线性光 float32，不在sRGB上直接平均。人物边缘支持扩缩、软遮罩、羽化和更保守的细节强度；按原图像素设置，输出放大时自动换算。不能保证修复神经模型已经生成的几何偏移，也不能靠羽化解决全部发丝／半透明材料差异。

人物投影、环境反光通常在人物遮罩之外，默认按环境处理。如需保护，请把它们加入人物保护区域，或降低环境强度。不存在“让两个独立渲染结果的光照自动物理一致”的承诺。

## 参数、色彩与预设

三组预设是初始建议值，未经用户GPU画质标定。预设的数值会同步到主节点。手调受预设控制的参数会切换自定义；API调用仍须明确选择自定义。预设覆盖原生光影、结构、皮肤结构、区域融合、人物／环境／统一光影强度、中性色与肤色保护、边缘保护；自定义模式才使用这些手动值。倍率、模型、风格、原生皮肤识别、遮罩羽化／扩缩、视频遮罩稳定等仍独立有效。输出report包含实际生效参数。

| 预设 | 原生光影／结构／皮肤结构 | 人物／环境细节 | 统一光影 |
|---|---|---|---|
| 人像保真 | 1.0／1.2／0.6 | 0.35／0.90 | 0.65 |
| 均衡增强 | 1.0／1.3／0.8 | 0.55／0.85 | 0.75 |
| 环境增强 | 1.2／1.6／0.6 | 0.30／1.00 | 0.85 |

中性色保护从**当前原图的同位置中性色**估计增强后色偏，有幅度限制，不执行整图均值／方差调色板迁移。肤色保护只用外接皮肤遮罩，以同位置原图皮肤色度为参考，保留增强亮度；不会把整身衣服当皮肤。缺可靠中性样本或缺皮肤MASK时，报告说明跳过，不强推颜色。

原生自动皮肤识别仅影响 `skin_structure`；外接skin_mask用于后处理的色度保护，两者不能互相替代。节点不把外接MASK注入模型内部，区域控制在渲染后进行。

## 预览与视频

先打开“整图预览模式”，最长边默认1024；缩小完整画面后执行原生增强，并限制预览输出长边。关闭后重新执行才能得到正式分辨率。预览与最终分辨率的纹理表现可能不同，不是免执行的滑块实时预览。

节点内局部对比在增强完成后裁ROI：左原图、右结果。可使用0～1的x/y/宽/高或外接roi_mask包围框。只比较首帧，不会把裁切小图送入DLSS。放大时原图缩放到相同输出尺寸后比较。

视频使用现有视频加载／合成节点，取其IMAGE帧批次接本节点并选择 `video_sequence`；不是新增一套视频文件编码器。必须按播放顺序输入，建议逐帧分割人物／皮肤。原生使用DIS光流，切镜重置历史；遮罩按反向光流传播并核对当前遮罩，明显不一致时使用当前结果，避免简单坐标平均产生拖影。中性色校正增益在连续镜头中平滑，切镜重置。

独立图片选 `independent_images`，每张强制重置历史，避免同批无关图片互相污染。单张MASK在视频中会广播，报告会警告；它不能代替人物追踪。分批视频在批次开始重置历史，不承诺跨批连续；输出图像＋遮罩超过2GiB时要求分批，长片需现有视频节点管理分段和编码。

渲染前默认卸载Comfy已加载模型释放显存，可关闭；并行LL DLSS任务会拒绝，防止争抢同一运行时和日志。取消或原生I/O超时会终止worker。成功必须有签名feature18执行证据，不能把普通缩放冒充DLSS增强。
