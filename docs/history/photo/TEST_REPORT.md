# 测试报告 · 2026-10-10 · v0.1.0

## 已实际执行

环境：Python 3.12.14，PyTorch 2.14.1+cpu，CPU 两线程。测试依赖仅安装在开发临时目录，没有修改用户服务器。

- **15 个测试方法全部通过**，原始日志见 unit-tests.log。
- 19 项参数分别测试正负极值；五项光影曲线测试全部 32 组极值组合，灰阶保持单调、不反转。
- 全零参数逐值不变，+1 EV 线性光量翻倍。
- 高光和阴影区域独立，黑白位可改变端点。
- 色温/色调方向正确，三区权重连续且和为 1。
- 极端分区调色在保持明度开启时，线性 Y 最大误差小于 5e-7。
- 非零处理保留 float32，4097 级渐变处理后仍超过 4000 个不同数值，没有降至 8 位。
- 批量、Alpha 保留、输入不变、半精度输入转 float32、非法输入处理通过。
- 分块/整图计算差异量级 3.58e-7，测试使用 5e-7 绝对容差；不是跨硬件逐位一致的承诺。
- 真实照片六组对照已生成并目视检查：原图、曝光、光影分区、白平衡、冷暖分区、对比度与自然饱和度。未观察到空间接缝；曝光 +0.7 案例可见亮部截断，不能当作高光恢复算法。
- 3840×2160 的组合调色测试耗时 **1.713 秒**，单次测量，输出尺寸及有限性检查通过。此数字不是目标服务器性能承诺。
- 真实照片来源：scikit-image v0.24.0 的 NASA astronaut 示例，来源及具体参数见 qa-metrics.json。
