# v0.6 人物主体提取与轮廓净化立项

立项日期：2026-10-24（北京时间）。用户已授权立项与开发。发布前在 STATUS.md 明确实际完成、验证和未验证部分。

## 问题与目标

电竞椅紧贴抬腿人物时，前置背景移除把椅背保留；旧轮廓节点用骨架几何与前景 MASK 取交集，未利用深度数值判断边界。强透视、交叉肢体与缺点回退会进一步影响结果。

目标：从原始 RGB 重新提取人物，前景 MASK 仅作软参考；深度参与局部边界提炼；区分完整人物提取与外扩轮廓修剪；最终同一 MASK 同步作用于 RGB、原深度。仅修剪可观测内容，不重建遮挡身体。

## 开发清单

1. SAM 2.1 成熟模型接入：利用骨架生成正／负提示，候选评分选择人物；支持手动保留／排除提示。可输入已有可靠人物 MASK，明确区分外部 MASK 模式与模型模式。
2. RGB 与局部深度联合边界细化：使用局部深度变化、RGB颜色边界和种子约束，不做全图固定深度阈值；前置粗遮罩允许修正。
3. 完整人物／修剪外扩两种模式；保留旧 LLPersonContourTrim 兼容。增强节点通过主体和局部边界拟合，减轻对全身统一宽度的依赖。
4. 同 MASK 输出净化 RGB、RGBA、深度（可选深度时提供明确说明）、保留遮罩、阶段预览与报告。无深度时为RGB模式，不冒充深度辅助。
5. 肤色辅助边缘净化：独立开关，默认关闭；基于高可信裸露肢体采样与局部深度证据，仅在肢体边缘检查，不以统一肉色阈值删除全身；暴露强度、检查带宽、保护程度。样本不足跳过并报告。
6. 显式诊断与部署：关键点不完整、模型缺失、边界不确定应提示；提供可控停止／保留策略。模型单独本地安装，无自动联网、无静默下载，不改动原Torch/CUDA。

## 验收

- 分别衡量非人物残留和真实肢体误删；回归椅子贴腿、强透视、坐姿、交叉肢体、宽裙、头饰与半身。
- 区分合成算法测试、真实模型推理和用户完整生图验证；截图不能替代原始POSE／深度数据。
- 默认关闭肤色增强，开关前后预览新增删除区域；衣物、手套、肤色阴影不应仅因颜色不同被删除。
- 同遮罩的RGB／深度输出保持画布与Alpha语义，支持批量与单帧提示广播，拒绝不同裁切误对齐。
- 所有旧节点测试继续通过，新增可复现样例、中文元数据、安装／离线权重说明和日志。

## 技术取舍

优先SAM 2.1提示式分割，现有骨架、RGB、深度辅助提示和细化。人体解析可输入可靠的裸露肢体遮罩，避免强制堆叠多个重模型；若自动裸露区域无法可靠估计，则肤色步骤跳过而不硬裁。人物／物体语义区分取决于模型与提示质量，不能承诺零误差。

采用记录：Meta SAM2 https://github.com/facebookresearch/sam2 （Apache-2.0）；既有Pillow绘图；RGB/深度细化采用成熟的种子分割算法并记录实际实现来源。
