1. 获得用户指定 ComfyUI 主机的实际执行通道。路径见 ACCEPTANCE.md；当前容器没有该环境。
2. 按 ACCEPTANCE.md 安装、启动并保留原始日志，不重装或更改现有依赖。
3. 执行 verify_server.py，检查十例真实 PNG 输出与后端注册。
4. 打开 UI 留存菜单截图，导入示例并切换五比例确认工作流可用。
5. 补齐真实证据后再更新 TEST_REPORT.md 和本日志，才能标记最终验收完成。
