# 人物主体提取、轮廓修剪与肤色净化使用指南

版本：v0.7.0；更新日期：2026-10-28（北京时间）。本指南整理完整功能讲解、接线、场景组合、手脚调节与排错方法。

**RMBG已抠好但裙尾／头花没去掉或手部变弱：优先读[SUBJECT_PRUNING.md](SUBJECT_PRUNING.md)。** v0.7新增原抠像保真、黑／白底输入类型及部位语义。external_mask本身不会调用SAM2，也不等于去饰品；语义默认off，需要启用并配置模型或外部部位MASK。

增强节点：**LL 人物主体提取·深度·肤色净化**，标识 LLPersonSubjectClean，分类「LL 节点库 / 图像工具 / 人物轮廓」。

旧节点 LLPersonContourTrim 继续保留，面向已有深度和前景MASK的几何修剪，没有人物语义／SAM2重新提取和肤色净化。v0.6.2给新旧两个节点都补充了独立脚掌、手掌保护。更新不会自动把旧节点换成增强节点。

## 四个处理环节

**原图人物提取 → RGB／深度边界细化 → 可选外扩修剪 → 可选肤色辅助净化。**

人物提取负责区分人与背景，深度帮助判断局部边界，外扩修剪减少原服装／饰品轮廓干扰，肤色辅助针对裸露肢体附近的异色异深度残留。各环节可以组合使用。手脚保护贯穿后续处理，避免已分割出的完整脚掌、鞋、手掌和手指再次被裁掉。

处理的是可见轮廓，不测量真实裸体体型，不补画衣服遮挡的身体，也不生成新深度。

## 推荐接线

| 输入 | 连接内容 | 作用 |
|---|---|---|
| 原始图像 image | 未经抠背景的原始RGB／RGBA | 保留人物颜色和完整图像证据 |
| 原始深度图 depth_image | 同一原图生成、未叠加骨架的深度 | 参与边界判断，输出净化深度 |
| 骨架关键点 keypoints | SDPose／DWPose的POSE_KEYPOINT数据 | 定位人物、肢体、手脚和外扩修剪区域 |
| 前景参考遮罩 foreground_mask | 原背景移除节点的MASK | 模型模式下作软参考，外部模式下作初始区域 |
| 强制保留遮罩 protect_mask | 白色圈出手脚、头发等 | 正向分割提示并强制保留 |
| 强制删除遮罩 exclude_mask | 白色圈出椅子、饰品等 | 负向提示并明确删除，最终优先级最高 |
| 裸露皮肤取样遮罩 skin_mask | 可靠裸露皮肤区域 | 限定肤色取样位置，不是整个人物保留轮廓 |

纠正误抠时优先接原图；已有可靠RMBG结果可接其黑／白底图和同一次MASK，并选择相应输入类型，避免二次Alpha。已丢失的颜色仍无法恢复。骨架要接关键点数据，不能接彩色骨架图片；深度使用与骨架混合之前的IMAGE。

RGB、深度、MASK必须是同一构图／裁切。等比例分辨率差异可自动映射；宽高比差异超过2%报错。同宽高比但裁切不同，不能自动识别和纠正。

## 三种分割来源

| 选择 | 实际行为 | 适合场景 |
|---|---|---|
| 人物语义引导SAM2 semantic_sam2，默认推荐 | 计算原图人物语义区域，引导SAM2；有骨架时用目标人物关键点，没有骨架时用分散语义提示 | 清除前置误抠残留、椅子／家具、普通人物提取 |
| SAM2骨架／保留提示 sam2 | 不运行人物语义模型，使用骨架或保留MASK提示SAM2 | 已有可靠骨架、自己指定目标或比较方案 |
| 外部人物遮罩细化 external_mask | 直接使用foreground_mask，再进行细化 | 原MASK已经较好，只需修边；不运行SAM2／语义模型 |

推荐模式会重新识别人，外部模式沿用旧MASK。SAM2模式中的前景参考MASK只参与候选评分，不与新结果硬取交集，旧MASK漏掉的区域仍有机会重新分割。

无骨架的推荐模式适合半身图，但可能保留多人。人物序号0是骨架中的第一人，选择其他人物需要骨架。增强节点没有旧节点-1「全部人物」选项，也没有跨帧身份追踪。

支持SAM2.1 Tiny／Small／Base Plus／Large选项，真实模型检查以Tiny为主。选择模型不会自动下载权重；推荐模式还需DeepLabV3 MobileNetV3人物语义权重。设备auto在CUDA可用时选GPU，否则CPU，安装见[SUBJECT_SETUP.md](SUBJECT_SETUP.md)。

## 深度边界细化

细化联合RGB边缘、深度边缘和相邻人物内部的局部深度差异，使用种子分水岭重新判断轮廓附近区域。它比较局部手臂、腿部附近的深度，不用全图统一灰度区间判断人体；伸腿与躯干不要求深度相同。深度图本身错误时，提高权重也可能增加误差。

| 参数 | 默认／范围 | 调节作用 |
|---|---|---|
| 边界提炼强度 | 0.7／0～1 | 增大允许调整的边缘范围；0关闭这一步细化，其他启用步骤仍执行 |
| 深度边界权重 | 0.65／0～1 | 增大更重视深度；0让边界细化只用RGB，不关闭肤色步骤的独立深度检查 |
| 边缘检查宽度 | 16／1～64 | 控制重新判断轮廓附近多宽的区域；过宽可能误裁 |
| 分析最长边 | 512／256～1024 | 可尝试768／1024增加细节采样，同时增加开销 |
| 边缘柔化 | 1／0～8 | 控制内部过渡；定位误裁时可以先用0 |

检查宽度、肤色检查宽度和柔化以**分析画布像素**为单位；提高分析尺寸后，同一数值对应的原图范围缩小。输出RGB保持原图尺寸。没有有效深度时使用RGB边缘，报告标出深度是否实际启用。

## 完整人物与外扩修剪

| 提取用途 | 作用 | 适合场景 |
|---|---|---|
| 完整人物 person，默认 | 保留正常衣物、头发，主要清除背景 | 电竞椅、家具、人物旁杂物 |
| 修剪外扩轮廓 body_trim | 在分割后按骨架和局部可见宽度继续限制轮廓 | 减少裙摆、宽袖、飘带、夸张头饰对动作条件的干扰 |

外扩修剪倍率默认1.0、范围0.5～1.8；减小收紧、增大放宽，可每次0.05调节。增强节点使用总倍率；旧节点保留头、躯干、手臂、腿部的分别调节。

外扩修剪需要较完整的身体主关键点。不足以建立轮廓时会跳过修剪、保留已分割人物并报告。没有骨架可先用推荐分割提取完整人物；连接了格式错误或有效提示太少的骨架可能报错。

原几何步骤结合可见轮廓与有界估计，本身不逐类识别饰品。v0.7部位语义可独立定位身体、候选衣料与局部头饰，替代整套骨架硬限制；仍不补画遮挡身体。模型可能漏分，可用明确删除MASK修正。

## 脚掌与手掌独立保护：v0.6.2新增

旧逻辑缺少脚部细点时只在脚踝保留小圆，有细点时主要使用固定宽度连线，鞋头、脚跟、宽脚掌可能超出范围；手掌也有固定尺寸和掌心覆盖不足的问题。原腿部／手臂倍率不会放大这些部位。

| 参数 | 默认／范围 | 实际作用 |
|---|---|---|
| 脚掌保护 foot_protection | 开启 | 保护完整脚掌／鞋的已分割区域，关闭可对照旧处理 |
| 脚掌保护范围倍率 foot_scale | 1.20／0.5～3.0 | 单独调整脚掌附近范围，不改变小腿倍率 |
| 手掌保护 hand_protection | 开启 | 独立保护掌心／手指，与脚掌、肤色开关互不依赖 |
| 手掌保护范围倍率 hand_scale | 1.15／0.5～3.0 | 单独调整手掌附近范围，不改变手臂倍率 |

关闭保护后对应倍率收起但数值保存。新参数作为optional追加，原控件顺序和节点类型保留，旧API可省略；旧工作流更新后使用新默认值，可关闭两项保护对照。

有脚趾／脚跟细点时，按这些点和脚踝构造完整脚掌范围并预留边缘；有手部细点时覆盖掌心和指尖之间的范围。初始分割中的真实指缝、脚间背景仍为空洞。细点也加入SAM2正提示，改善初始覆盖机会。

缺少细点时，用脚踝／手腕和相邻骨骼建立局部候选范围，取其中已有的可见前景。手部缺细点时默认范围较保守，避免手靠近腰部时把裙摆当成手掌保护；可独立加大范围。没有有效脚踝／手腕时跳过该部位，不猜测位置。

优先接官方SDPose原始关键点，通常包含脚6点和双手各21点。部分DWPose输出只有身体18点、没有脚部细点；手部需要开启输出。SDPose绘图节点是否显示脚部，只影响绘图，使用时仍接原始keypoints。

**增强节点的自动保护受初始分割约束**：放大范围不会补出初始分割漏掉的脚趾／鞋头，也不会从初始背景中画出前景。保护在边界、外扩修剪、肤色和柔化后保持已有手脚，明确删除MASK始终优先。范围过大也可能保留初始MASK里粘连的椅子／衣物，需要缩小倍率或接删除MASK。

脚掌仍裁多时：
1. 看三阶段左图。左图已缺脚，先改善分割、提供细点或保留提示；单加保护倍率不能恢复漏分。
2. 左图完整、后两图变小时，保持脚掌保护开启，将1.20逐步调到1.40、1.60，观察鞋头、脚跟和外缘。
3. 检查关键点位置／置信度与裁切对齐，必要时提供局部保留MASK。
4. 多保留椅子或裙摆时缩小脚掌范围或用删除MASK，无需放宽整条腿。

手掌同理，可从1.15逐步尝试1.30、1.50。这些是调试起点，不是所有图片适用的固定预设。倍率只调整保护范围，缩小它不会让原有正常轮廓必然同比变小；精确删除某一块用exclude_mask。

报告extremities.parts按左右手脚列出source和observed_pixels：wholebody_landmarks表示细点，local_foreground表示缺细点时采用局部前景估计；像素数不是识别精度或人体测量。

## 肤色辅助边缘净化：已实现，默认关闭

打开skin_enabled后展开三个参数；关闭收起界面并停用该步骤，数值仍保存。它从骨架定位的手臂、腿部内部取样，使用图内皮肤色度统计，联合局部深度检查边缘。

只有同时位于对应肢体边缘、色度明显偏离可靠样本、局部深度也不一致时，才由该步骤删除。适合裸露手臂／腿部旁的异色异深度残留，例如粉色椅子贴着腿；亮暗变化本身不直接作为肤色差异。

| 参数 | 默认／范围 | 调节方式 |
|---|---|---|
| 肤色净化强度 | 0.5／0～1 | 残留明显逐步提高，误裁先降低 |
| 肤色检查宽度 | 10／1～48 | 调整内侧边缘检查范围，与强度共同影响实际范围 |
| 肢体保护程度 | 0.7／0～1 | 越高越保守，优先保护正常肢体 |

**肤色辅助已有，通用材质分类尚未实现。** 自动皮肤取样是颜色启发式，不是独立皮肤语义网络，不区分丝袜、皮革、布料。彩色光、肤色衣物、近肤色家具可能干扰。丝袜、手套、长袖图片先关闭肤色增强，主要用人物、深度与轮廓修剪。

skin_mask可接人体解析的皮肤MASK，或手工圈出的可靠裸露肢体，限定取样位置；它不直接决定整个人物保留范围，仍需骨架和有效深度。

没有有效深度、可定位肢体、足够可靠样本时会跳过并报告。打开开关不代表一定删除，可看sampled_parts和removed确认。手脚保护与肤色开关独立，穿鞋也可开启脚掌保护，保护范围内已有手脚不会因肤色步骤异常再被裁掉。

## 场景组合与调节顺序

| 场景 | 建议起点 |
|---|---|
| 电竞椅背景残留 | 推荐分割＋原深度＋骨架，先完整人物；裸露肢体边缘仍有残留再开肤色 |
| 裙摆、宽袖干扰动作 | 推荐分割＋原深度＋完整骨架，切换外扩修剪，trim_scale从1.0开始 |
| 丝袜、长袖、包裹服装 | 肤色先关闭，手脚保护保留，使用人物分割、深度和轮廓 |
| 近镜头大脚、长鞋、强透视 | 先确认初始分割完整，再增加foot_scale，必要时接保留MASK |
| 张开的手、宽手套 | 接手部21点，独立增加hand_scale，检查掌心和指尖 |
| 少量明确杂物 | 用exclude_mask局部删除，避免只提高全局强度 |
| 已有准确MASK | external_mask细化，省去人物语义／SAM2推理 |
| 无骨架半身图 | 推荐分割＋完整人物，手脚／肤色／外扩可能跳过 |

动作参考先固定「原图＋原深度＋骨架 → 推荐分割 → 完整人物 → 看预览」，再逐项启用外扩、肤色或调节手脚。优先一次改变一项，区分改善和误裁来自哪一步。

## 输出与排错

| 输出 | 用途 |
|---|---|
| 净化RGB clean_rgb | 后续图像参考、预览、保存，黑／白背景可选 |
| 透明RGBA rgba | 原RGB配最终Alpha，输入原有Alpha继续约束 |
| 净化深度 clean_depth | 原深度乘同一对应MASK，保持深度原画布，接深度条件 |
| 保留遮罩 keep_mask | RGB原画布最终MASK，白色保留 |
| 三阶段对比 stage_preview | 左到右：初始主体、RGB／深度与语义细化、最终修剪；绿保留、红删除 |
| 肤色步骤删除区域 skin_removed_mask | 只显示肤色新增且最终实际删除区域，保护恢复的像素不计入 |
| 处理说明 report | 深度启用、肤色取样／删除、修剪跳过、手脚保护来源和异常回退 |

**未输入深度时clean_depth是全黑占位，不能接深度条件。** 单纯提取RGB仍可执行。RGB与深度使用同一对应MASK，不进行两次独立分割。

异常策略默认stop：保留面积不足初始主体30%时停止提醒检查。keep_subject会保留初始人物并明确警告／报告；模型缺失、参数和输入错误始终报错。节点运行结束不等于发生了有效修剪，需检查report。

支持RGB／RGBA浮点IMAGE、批量、单帧深度／MASK／静态骨架广播、OpenPose18／25、像素／归一化坐标自动适配，并接受DWPose可选部位为null。BODY25会读取其脚部6点。运动视频应逐帧给骨架，增强节点没有跨帧追踪；旧节点批内平滑不等于身份追踪。

## 旧节点与更新

旧轮廓节点先按骨架／前景拟合，再限制原深度；v0.6.2同样增加手脚四项控制，但没有新人物分割和肤色净化。接前景MASK时手脚保护受它约束；未接MASK时只能使用有界几何范围，可能保留附近背景，报告会提示。已有前置误抠和RGB输出需求时，优先增强节点。旧节点说明见[CONTOUR_TRIM.md](CONTOUR_TRIM.md)。

更新整个插件目录、重启ComfyUI、Ctrl+F5。新建节点可查看新增参数；旧实例没有显示时保存工作流后重启刷新，必要时新建同类型节点对照。没有新增依赖或模型，已安装SAM2与两份权重继续使用。

示例depth_workflow.json／rgb_only_workflow.json位于examples/subject，可拖入ComfyUI，对应*_api.json用于API。原端口和输出序号保持兼容，新四项参数追加。

## 验证范围

v0.6曾检查真实SAM2／人物语义、抬腿电竞椅图与公开半身图。电竞椅使用手工可见关键点和新推理Depth Anything V2 Small深度，不是用户原始POSE／深度，肩后仍有少量残留。

v0.6.2增加完整脚掌／鞋、掌心／手指、缺细点、独立倍率、肤色／深度后保护等回归，并用公开COCO WholeBody鞋靴照片及标注骨架／前景检查保留范围。本轮未在用户本机跑SAM2、SDPose或最终SD生成，也没有大规模脚掌／鞋型数据集验收。粘连MASK、近肤色家具、严重遮挡和关键点偏移仍需结合预览及局部MASK修正。
