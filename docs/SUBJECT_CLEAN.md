# 人物主体提取、深度提炼与肤色辅助净化

节点：`LLPersonSubjectClean`；分类：LL 节点库 / 图像工具 / 人物轮廓。旧 `LLPersonContourTrim` 保留，不会自动替换旧工作流中的节点。

## 接线

1. 未经抠背景的原始RGB → `image`。不要先把抠错区域填黑，否则原图证据已经丢失。
2. 同一原图得到的原始深度 → `depth_image`；SDPose／DWPose原始关键点 → `keypoints`。两者可选，但外扩修剪和自动肤色肢体定位需要骨架。
3. 原背景移除MASK可接 `foreground_mask`，在默认模型模式中仅参与候选评分，不与结果硬取交集。
4. 后续RGB参考使用 `clean_rgb`；深度条件使用 `clean_depth`；独立透明图使用 `rgba`，同时可取 `keep_mask`。

RGB、深度、MASK必须是相同构图／裁切。等比例分辨率差异自动映射；不同宽高比会报错。同宽高比的不同裁切不能自动识别，需自行确认。

## 模式

| 设置 | 行为 |
|---|---|
| `semantic_sam2`（默认推荐） | 从原图计算人物语义概率，作为SAM2遮罩提示；有骨架时用指定人物关键点，没有骨架时自动提取语义人物，可能包含多人。 |
| `sam2` | 不运行人物语义模型；必须提供骨架或强制保留MASK作正提示，主要用于比较或自定义流程。 |
| `external_mask` | 把foreground_mask作为初始人物区域，再进行RGB／深度细化；此模式不是重新识别人。 |
| `person`（默认用途） | 保留完整人物，包括其正常衣物与头发，重点排除背景物体。 |
| `body_trim` | 主体提取后继续按骨架与局部观测宽度修剪外扩；不补画遮挡身体。完整骨架不足时保留已分割人物并报告跳过修剪。 |

深度提炼在局部边缘带内执行：RGB与深度梯度、局部内部深度参考构成分水岭边界，深度权重默认0.65。它不是把全图某一段灰度当作人体，也不会生成新深度。无有效深度时使用RGB边缘，报告会明确说明。

分析最长边默认512，输出RGB保持原分辨率。提高到768／1024可改善细节采样，同时增加耗时；边缘带宽、肤色检查带宽、柔化参数以分析画布像素为单位。

强透视下不再以骨架点的极值作为SAM裁切框；外扩修剪局部宽度允许从已分割主体扩大观测，减少统一躯干尺度造成的误切。但大脚、缺失脚趾点、交叉肢体和大裙摆仍可能需要保留／排除MASK修正。

## 肤色辅助边缘净化（默认关闭）

打开开关后展开三个参数：强度、检查宽度、肢体保护程度。关闭后收起，参数数值仍保存，但该步骤不执行。

此步骤在骨架对应的手臂、腿部内部取色，比较肢体内侧边缘的颜色偏离与局部深度偏离；两类证据同时成立才删除。肤色使用图内颜色统计，亮度变化不直接作为肤色差异。可用 `skin_mask` 限定可靠的裸露皮肤采样，推荐接人体解析的皮肤区域。

自动裸露皮肤取样使用保守颜色启发式，并不具备服饰／皮肤语义保证。手套、彩色灯光、肤色相近的衣物或椅子可能导致跳过或判断不准确。没有有效深度、没有骨架肢体区域、样本不足时跳过并写入报告；不会只因颜色不同就删除整件衣服。需要修正时先降低强度、提高保护程度或连接明确的皮肤取样MASK。

## 输出与诊断

| 输出 | 含义 |
|---|---|
| `clean_rgb` | 原RGB乘最终有效遮罩，背景黑／白可选 |
| `rgba` | 原RGB + 最终Alpha；输入原有Alpha也会保留约束 |
| `clean_depth` | 原深度乘对应遮罩，保持深度原画布；**未接深度时是全黑占位，不可当作深度条件** |
| `keep_mask` | RGB原画布上的最终保留遮罩，白保留 |
| `stage_preview` | 从左到右：初始主体、RGB／深度细化、最终修剪；绿保留、红删除 |
| `skin_removed_mask` | 仅肤色步骤新增且最终实际删除的区域，白色代表删除 |
| `report` | 是否启用深度、肤色采样部位数／删除像素数、缺点与回退等JSON说明 |

`protect_mask` 强制保留，`exclude_mask` 强制删除，删除最终优先。RGB与深度根据同一遮罩对应，不使用两个独立分割结果。批量图像可广播一张参考深度／MASK／静态骨架；运动序列应逐帧输入骨架，不提供跨帧追踪。

默认异常策略为停止：自动结果保留面积不足初始主体的30%时提醒检查，防止严重误裁。可选择保留初始人物，此时报告和服务端警告都会说明回退。模型缺失或输入错误始终报错，不会偷偷切换旧算法。

## 验证范围

本版做了真实SAM2／人物语义推理、用户抬腿电竞椅图与公开半身照片检查，以及合成的深度分界、肤色误差、批量／Alpha测试。电竞椅验证使用手工可见关键点和本地新推理的Depth Anything V2 Small深度，不是用户工作流原始POSE／深度；椅子主体残留明显减少，但肩后等位置仍有少量残留。

未在用户ComfyUI服务器／CUDA环境联调，未运行完整SD生图链路，也没有大规模真实宽裙／头饰／交叉肢体数据集验收。本版本提供可用实现与可检查输出，不承诺所有姿态自动抠净。后续优先用用户实际输入继续回归。
